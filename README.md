# Kids Coding Thinking Skills Landing Page

A playful, responsive, single file landing page for **5 Ways Learning to Code Boosts Your Child's Thinking Skills**.

Visitors can program a tiny robot with tap blocks, then explore five ways coding for kids builds logic, creativity, patience, STEM learning and confidence.

## Features

- Interactive block game that teaches sequencing in seconds
- Five flip style idea cards with "try at home" tips
- Python section with a readable code sample
- Sticky header, bold call to action section and full footer
- Fully responsive, keyboard friendly and respects reduced motion
- Palette: beige, brown, orange, white and baby pink
- No build step, no dependencies beyond Google Fonts

## Run locally

Open `index.html` in any modern browser.

## Deploy with GitHub Pages

1. Push `index.html` and `README.md` to the `main` branch.
2. Go to **Settings > Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. Your site goes live at `https://<your-username>.github.io/<repository-name>/`.

## Customise

Colours live in the `:root` block at the top of the stylesheet. Change the five variables to retheme the whole page.
